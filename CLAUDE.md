# GhostQPU

Hackathon MVP (Q-Hack India 2026, Quantum Security & Cryptography track) that detects quantum cloud jobs faked by a simulator built from IBM's public calibration data. Hidden **canary** circuits ride along with the customer's workload; a small Detector turns their results into a Genuine / Forged / Inconclusive verdict.

Scope is "demo-able MVP", not research grade. Prefer a working end-to-end path and a clear demo over statistical rigor. Canary-aware forger and cross-backend studies are future work (see PLAN.md).

## Commands

Windows venv paths shown; use `.venv/bin/python` on macOS / Linux.

```sh
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m pytest                 # ~1 min, no QPU time
.venv/Scripts/python -m ruff check .           # must stay clean
.venv/Scripts/python -m streamlit run app.py   # dashboard; ?data=stand_in for the null test view
.venv/Scripts/python -m ghostqpu null-test     # simulator vs Forger, must score near chance
.venv/Scripts/python -m ghostqpu evaluate      # held-out Detector report on data/runs
```

Hardware commands (`add-account`, `accounts`, `submit`, `collect`) spend real IBM QPU time on the free Open plan (600 s per 28 days, ~11 s per job). Never run `submit` without the user asking.

## Layout

```
ghostqpu/
  snapshot.py    CalibrationSnapshot: capture / save / load / simulator_backend
  canaries.py    build_batch(snapshot, seed) -> Batch (canaries hidden among workload circuits)
  runs.py        Run: shot records + batch + snapshot; save / load_runs
  execution.py   submit / collect (IBM Sampler), forge_twin(run), stand_in_run (local)
  signature.py   signatures(run, n_chunks): 12 canary features per time-ordered chunk
  detector.py    dataset / train / verdict / evaluate (held out by cycle, else by run pair)
  cli.py         argparse entry point (python -m ghostqpu ...)
app.py           Streamlit + Altair dashboard (Verify a job, Evidence, Detector)
data/runs/       committed Genuine ibm_marrakesh runs and their Forged twins
data/stand_in/   generated by null-test (gitignored)
data/pending/    submitted jobs awaiting collect (gitignored)
tests/           pytest suite
docs/, demo/     explainer PDF, slides, demo video
```

## Invariants and gotchas

- **Same Run shape on both paths.** The honest path (IBM runtime Sampler) and the Forger (direct Aer with `memory=True`) must produce identical `Run` objects. Swapping one for the other is exactly the attack. `tests/test_execution.py` has a bit-column parity test; keep it passing.
- **Bit layout:** canary placement `i` uses clbit `2i` for the target and `2i+1` for the neighbor. Aer memory strings are reversed into little-endian bit arrays in `_memory_to_bits`.
- **Canaries are transpiled at optimization level 0** with an explicit `initial_layout` so they run exactly as written. Workload circuits use level 1.
- **Sampler options:** dynamical decoupling and twirling (gates and measure) are off. Turning them on would erase the effects the canaries measure.
- **Noise model on Heron:** `NoiseModel.from_backend_properties` crashes (no `frequency`). The snapshot is rebuilt into a `FakeBackendV2` subclass (`_SnapshotBackend`) and fed to `NoiseModel.from_backend`.
- **The Forger uses the execution-time calibration** (fetched from `job.metrics()` running timestamp on collect), so it is the strongest fair attacker. Don't weaken it.
- **Detector evaluation must never see the job it scores** or that job's twin. Keep the held-out split.
- **Null test must stay near AUC 0.5.** If a change makes it separate stand-ins from the Forger, the Detector is picking up an artifact, not physics.
- Use `qiskit_ibm_runtime.executor_sampler.Sampler`, not the deprecated `SamplerV2`. Tests run with `-W error::DeprecationWarning`.
- Altair charts: blue `#2a78d6` = Genuine, orange `#eb6834` = Forged. Use `width="stretch"`, not `use_container_width`.

## Secrets

IBM API keys are saved locally through `python -m ghostqpu add-account` (read with `getpass`) into the Qiskit account file in the user's home directory. Never write a key into this repo, a commit, a log, or a doc. The repo is public.
